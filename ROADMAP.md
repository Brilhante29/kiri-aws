# `kiri-aws` Project Roadmap

This document outlines the high-level roadmap and feature direction for **`kiri-aws`**.

## Q3 2026 — Foundation & Deterministic Billing
- [x] High-performance AWS Service Emulation Engine (127+ services supported).
- [x] Deterministic AWS Billing Engine (`Cost Explorer API` + `Budgets`).
- [x] Time Machine API (`/_kiri/time/advance`) for fast-forwarding simulated time.
- [ ] Expanded KMS key rotation and asymmetric signing simulations.

## Q4 2026 — Advanced Emulation & Integrations
- [ ] Full S3 Lifecycle Rules simulation engine.
- [ ] Improved Step Functions (SFN) State Machine Execution Engine.
- [ ] Multi-region sync simulation mode.
- [ ] Enhanced OpenCode & Claude Code MCP integration tools.

## 2027+ — Multi-Cloud Extensions
- [ ] Modular GCP and Azure emulation plugins under unified local runtime.
